# How to contribute

This repository is the public dashboard and front-end for PortaD. It is designed for contributors working on UI, docs, accessibility, product polish, and dashboard flows.

## What belongs here

This repo is the right place for:
- frontend and UX improvements
- landing page and marketing site updates
- migration wizard and compatibility UI work
- accessibility and responsiveness improvements
- docs or onboarding updates for the dashboard experience

This repo is not the primary home for:
- core migration logic
- adapter implementation
- CLI behavior
- specification and data model changes

Those live in the core PortaD repository: https://github.com/IndianjobsTech/PortaD

## Ways to contribute

### UI and product work
- improve page layouts and components
- improve responsiveness and accessibility
- polish the onboarding flow
- add or refine FAQ content

### Documentation
- improve setup instructions
- add examples and screenshots
- document app structure and app flows

### Quality and maintenance
- fix lint issues
- improve test coverage
- catch issues in browser behavior
- review accessibility and keyboard navigation

## Starting a contribution

1. Read [CONTRIBUTING.md](../CONTRIBUTING.md)
2. Check the issue tracker for an existing discussion
3. Open a new issue if your idea is large or unclear
4. Create a branch and keep changes focused
5. Run lint and build checks before opening a PR

## Suggested good first tasks

Look for issues labeled:
- `good first issue`
- `help wanted`
- `documentation`
- `ui`
- `accessibility`

## Communication

- Use GitHub Issues for bugs and feature requests
- Use GitHub Discussions for general questions and broader ideas
- Keep discussions clear and respectful

We welcome thoughtful contributions that improve the dashboard experience for users and contributors.
